Spotify setup, step by step
  1. Open the Spotify Developer Dashboard and sign in with the Spotify account you want to use.
  2. Click Create app, enter a name and description, select Web API and Web Playback SDK if Spotify asks which APIs you plan to use, accept the terms, and save.
  3. Open the new app, copy its Client ID (not Client Secret), then paste it into the field directly below.
    Spotify Client ID Paste the Client ID from Spotify Developer Dashboard here. Better Song Request needs only this public identifier, never Client Secret.
    Redirect URI required for Spotify OAuth
    Paste this exact address into Spotify Developer Dashboard > your app > Settings > Redirect URIs, then save the Spotify app settings. The address must match exactly, including 127.0.0.1, port, folder name, and index.html.
  4. In Spotify Developer Dashboard, open your app's Settings. Expand the Redirect URI panel below step 3, copy the exact address to Redirect URIs, and save. Keep 127.0.0.1; do not replace it with localhost.
  5. Return here, enable Spotify integration, click Connect Spotify, and approve the requested access.
  6. Open Better Song Request through Streamer.bot's HTTP server. If login fails, verify that the port, folder path, and Redirect URI are identical.

🎓 Tutorial: First steps

1. Interface and Features

• Left Panel (Base): Here you will find tracks from your YouTube and Spotify playlists. The player randomly shuffles songs from them when the viewer queue is empty. You can add more playlists or remove the default one in the Playlist Manager (📁).
• Middle Panel: Bot/API status, !SR switch, Settings gear icon, and the active YouTube/Spotify player.
• Right Panel (!SR Queue): Viewer requests from chat. You can Drag & Drop tracks here with your mouse to easily change their order!

Queue Saving and Request Limits

Use the small switch in the Now Playing section to keep the current queue after refreshing the page. Request limits control accepted track length, music category checks, queue capacity, and !voteskip.

Settings > General > !SR Request Limits

2. HTTP Server in Streamer.bot

For the player, APIs, and Spotify login to work without browser blocks, the file must be run through a local HTTP server. In Streamer.bot go to the Servers/Clients -> HTTP Server tab.

3. WebSocket Server in Streamer.bot

An active WebSocket connection carries chat commands and player status between Better Song Request and Streamer.bot. Configure it in Servers/Clients -> WebSockets -> Server. Use the same port and optional password on both sides.

Settings > General > WebSocket Server (Streamer.bot)

OBS Now Playing Widget

Customize the Now Playing widget and copy its generated URL into an OBS Browser Source.

Settings > General > OBS Widget Configuration

4. Import Actions to Streamer.bot

For chat commands (!sr, !voteskip, !skip, deleting, etc.) to work, you need specific action commands and queues in Streamer.bot.
